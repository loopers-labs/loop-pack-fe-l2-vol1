# 5주차 상태 설계

TanStack Query — 서버 데이터
nuqs — URL에 있어야 하는 것
Zustand — 여러 페이지가 공유하는 것
React 로컬 state — 한 화면에서만 쓰는 것

| 상태                                                                 | 소유자          | 수명                  | 공유 범위  | 선택 이유                                 |
| -------------------------------------------------------------------- | --------------- | --------------------- | ---------- | ----------------------------------------- |
| 홈 배너, 카테고리, 인기상품, 신상품                                  | TanStack Query  | 홈 페이지 있는 동안   | 홈 페이지  | 서버에서 오는 데이터                      |
| 검색·카테고리·정렬·페이지                                            | nuqs            | URL에 있는 동안       | URL        | 새로고침·공유·뒤로가기 후 복원이 필요해서 |
| 여러 페이지에서 함께 쓰는 비로그인 사용자의 로컬 장바구니·위시리스트 | Zustand         | 앱 켜져 있는 동안     | 앱 전체    | 여러 페이지에서 사용하기 위해서           |
| 모달 열림 여부, 제출 전 입력 초안                                    | React 로컬 상태 | 페이지 있는 동안      | 페이지     | 한 화면에서만 쓰는 일시적 상태라서        |
| 목록 상품 데이터                                                     | TanStack Query  | 목록 페이지 있는 동안 | 목록페이지 | 서버에서 오는 데이터                      |
|                                                                      |                 |                       |            |                                           |
