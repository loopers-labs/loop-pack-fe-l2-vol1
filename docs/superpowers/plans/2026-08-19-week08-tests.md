# Week 08 Tests Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 커밋된 2-9-4 설계대로 15개 검증 항목을 구현하고 production E2E까지 `pnpm check`에서 검증한다.

**Architecture:** Vitest projects로 순수 Node 테스트와 jsdom 통합 테스트를 분리한다. 통합 테스트는 실제 React Query와 Zustand를 사용하고 MSW가 제품 코드의 HTTP 요청을 가로채며, 브라우저 고유 계약 네 개는 Playwright로 검증한다.

**Tech Stack:** TypeScript, Vitest, React Testing Library, user-event, jest-dom, jsdom, MSW, TanStack Query, Zustand, nuqs, Playwright

**Spec:** `docs/rfc/week08-test-plan.md`

## Global Constraints

- pnpm만 사용하고 Node 22.12.0 이상에서 검증한다.
- 제품 HTTP 클라이언트나 fetch 응답을 직접 mock하지 않는다.
- 단위 테스트는 DOM 없이, 통합 테스트만 jsdom에서 실행한다.
- 통합 네트워크 예외는 테스트별 `server.use`로 선언한다.
- E2E는 production build 위에서 고정 sleep 없이 실행한다.
- 실제 테스트 파일은 이 계획의 근거인 RFC 커밋 `64b5edb6` 뒤에만 추가한다.
