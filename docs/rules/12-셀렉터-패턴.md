# 12 — 셀렉터 패턴

## When to read

store selector, 파생값, 구독 범위, memoization 계약을 작성하거나 변경할 때 읽는다.

## Source of truth

- 전역 상태: [`./04-상태-관리.md`](./04-상태-관리.md)

## Rules

### 1. selector는 최소한의 값만 구독한다

- 컴포넌트는 필요한 값만 selector로 선택해 구독한다.
- 전체 store를 구독하면 store의 어느 값이 바뀌어도 리렌더가 발생한다.

| ✅ 올바른 예                                      | ❌ 잘못된 예                                         |
| ------------------------------------------------- | ---------------------------------------------------- |
| `useCartStore((state) => state.items[productId])` | `useCartStore((state) => state)`                     |
| `useCartStore(cartSelectors.count)`               | `const { count, addToCart, items } = useCartStore()` |

### 2. action은 별도 selector로 가져온다

- action은 참조 안정성이 보장되어야 하므로 별도 selector로 가져온다.
- selector와 action을 한꺼번에 구독하면 action 참조가 바뀔 때 불필요한 리렌더가 발생할 수 있다.

```ts
// ✅ 올바른 예
const count = useCartStore(cartSelectors.count)
const addToCart = useCartStore((state) => state.addToCart)

// ❌ 잘못된 예
const { count, addToCart } = useCartStore((state) => ({
  count: Object.keys(state.items).length,
  addToCart: state.addToCart,
}))
```

### 3. 파생값은 selector에서 계산한다

- 계산 가능한 값은 별도 상태로 중복 저장하지 않고 selector에서 파생한다.
- 복잡한 파생은 selector 유틸로 분리하고 테스트로 보호한다.

| ✅ 올바른 예                                               | ❌ 잘못된 예                                      |
| ---------------------------------------------------------- | ------------------------------------------------- |
| `cartSelectors.count = (s) => Object.keys(s.items).length` | store에 `count` 필드를 추가하고 action마다 갱신   |
| `wishlistSelectors.isInWishlist(id)`                       | 컴포넌트마다 `state.wishlist.includes(id)`를 반복 |

### 4. memoization은 필요할 때만 적용한다

- selector가 참조 안정성을 보장해야 하는 경우에만 memoization을 사용하고 이유를 설명한다.
- 배열/객체를 반환하는 selector는 참조 불안정으로 리렌더를 유발할 수 있다.

```ts
// ✅ 올바른 예: 복잡한 파생 배열에 memoization
const sortedProducts = useMemo(
  () => sortProducts(products, sort),
  [products, sort],
)

// ❌ 잘못된 예: 단순 boolean selector에 memoization
const isInCart = useMemo(() => !!items[productId], [items, productId])
```

## Verification

- selector가 불필요한 리렌더를 일으키지 않는지 확인한다.
- 파생값이 상태와 일치하는지 테스트로 보호한다.
- action selector가 참조 안정성을 유지하는지 확인한다.
