# 08 — 모달·토스트

## When to read

모달, 다이얼로그, 드롭다운, 토스트, 일시적 UI 피드백을 작성하거나 변경할 때 읽는다.

## Rules

### 1. 열림 상태는 기본적으로 로컬 상태다

- 모달·드롭다운 열림 여부는 한 화면에서만 쓰는 일시적 UI 상태이므로 React 로컬 상태로 둔다.
- 전역 store에 넣으면 불필요한 리렌더와 store 복잡도만 증가한다.
- 열림 상태를 URL에 노출해야 하는 경우(공유 가능한 모달 등)는 nuqs를 고려한다.

| ✅ 올바른 예                              | ❌ 잘못된 예                     |
| ----------------------------------------- | -------------------------------- |
| `const [open, setOpen] = useState(false)` | `useModalStore((s) => s.open)`   |
| URL 공유 모달은 `?modal=terms`로 관리     | 모든 드롭다운 상태를 전역에 등록 |

### 2. 재사용 가능한 다이얼로그는 조합 가능하게 만든다

- compound component나 headless 패턴을 사용해 trigger, content, overlay, close를 조합할 수 있게 한다.
- 하나의 `Modal` 컴포넌트에 모든 콘텐츠를 props로 밀어넣지 않는다.

```tsx
// ✅ 올바른 예
<Dialog>
  <DialogTrigger>열기</DialogTrigger>
  <DialogContent>
    <DialogTitle>제목</DialogTitle>
    <DialogDescription>설명</DialogDescription>
  </DialogContent>
</Dialog>

// ❌ 잘못된 예
<Modal title="제목" description="설명" body={<Form />} footer={<Buttons />} />
```

### 3. 접근성 계약을 함께 설계한다

- 모달/토스트는 focus trap, ESC 닫기, 포커스 복원, `aria-modal`, `role="dialog"` 등 접근성 계약을 함께 설계한다.
- 토스트는 `role="status"` 또는 `role="alert"`로 알려야 한다.

| 요소              | 필수                         |
| ----------------- | ---------------------------- |
| 모달 열림         | 첫 포커스를 모달 내부로 이동 |
| 모달 닫힘         | 포커스를 trigger로 복원      |
| ESC               | 모달/드롭다운 닫기           |
| 배경 클릭         | 닫기 옵션 명시               |
| `aria-labelledby` | 모달 제목과 연결             |

### 4. 토스트는 중복과 flooding을 방지한다

- 동일한 메시지가 연속으로 쌓이지 않도록 id 기반 deduplication을 적용한다.
- 자동 dismiss 시간은 콘텐츠 길이와 중요도에 따라 조정한다.
