# 9주차 E2E 에이전트 테스트 계획

## 범위

- 인증 플로우
- 체크아웃/주문 플로우

상품 탐색, 담기 단독 동작, 위시리스트, 상품 상세는 이번 E2E 범위에 포함하지 않는다.

## 인증 플로우

### 1. 세션 쿠키가 있으면 JavaScript 실행 전에도 주문서 Header에 사용자 이름을 보여준다

**Steps**

1. JavaScript를 비활성화한 browser context를 만든다.
2. API로 로그인해 세션 쿠키를 만든다.
3. `/order`로 진입한다.

**Assertions**

- Header에 `루퍼1님`이 보인다.

### 2. 세션 쿠키가 있으면 JavaScript 실행 전에도 주문 내역 Header에 사용자 이름을 보여준다

**Steps**

1. JavaScript를 비활성화한 browser context를 만든다.
2. API로 로그인해 세션 쿠키를 만든다.
3. `/orders`로 진입한다.

**Assertions**

- Header에 `루퍼1님`이 보인다.

### 3. 미로그인으로 보호 경로에 진입하면 로그인 후 원래 경로로 복원된다

**Steps**

1. 미로그인 상태로 `/order`에 진입한다.
2. 로그인 페이지로 이동했는지 확인한다.
3. 올바른 이메일과 비밀번호를 입력한다.
4. 로그인 버튼을 누른다.

**Assertions**

- `/login?redirectTo=%2Forder`로 이동한다.
- 로그인 성공 후 `/order`로 돌아온다.
- 주문서 heading이 보인다.

### 4. 잘못된 비밀번호로 로그인하면 로그인 페이지에 머물며 실패 메시지를 보여준다

**Steps**

1. `/login`에 진입한다.
2. 올바른 이메일과 틀린 비밀번호를 입력한다.
3. 로그인 버튼을 누른다.

**Assertions**

- `이메일 또는 비밀번호를 확인해주세요.` 메시지가 보인다.
- URL은 `/login`에 머문다.

### 5. expired 시나리오로 주문 내역에 진입하면 현재 화면을 유지하고 로그인 안내 모달을 보여준다

**Steps**

1. API로 로그인한다.
2. `scenario=expired` 쿠키를 추가한다.
3. `/orders`에 진입한다.

**Assertions**

- URL은 `/orders`에 머문다.
- `세션 만료` dialog가 보인다.
- `세션이 만료되었습니다. 다시 로그인해주세요.` 문구가 보인다.
- `로그인하기` 링크의 href는 `/login?redirectTo=%2Forders`다.

### 6. 주문 생성 API가 401을 응답하면 주문서 화면을 유지하고 로그인 안내 모달을 보여준다

**Steps**

1. API로 로그인한다.
2. 장바구니 localStorage에 주문 가능한 상품을 넣는다.
3. `/order`에 진입한다.
4. `/api/orders` 요청이 401을 응답하도록 만든다.
5. 주문 완료 버튼을 누른다.

**Assertions**

- URL은 `/order`에 머문다.
- `세션 만료` dialog가 보인다.
- `로그인하기` 링크의 href는 `/login?redirectTo=%2Forder`다.

## 체크아웃/주문 플로우

### 7. 로그인한 사용자가 장바구니에서 주문을 완료하면 주문 내역에서 확인할 수 있다

**Steps**

1. `storageState`로 로그인 상태의 browser context를 만든다.
2. `/products`에 진입한다.
3. 상품 목록이 보이는지 확인한다.
4. 첫 번째 상품을 장바구니에 담는다.
5. Header의 장바구니 링크로 `/cart`에 이동한다.
6. 선택된 장바구니 상품을 확인한다.
7. 주문하기 링크로 `/order`에 이동한다.
8. 주문서에서 선택 상품과 수량을 확인한다.
9. 주문 완료 버튼을 누른다.
10. `/orders`로 이동한다.

**Assertions**

- 상품 목록 heading이 보인다.
- 장바구니 개수가 `0`에서 `1`로 바뀐다.
- `/cart`로 이동한다.
- 장바구니 상품 checkbox가 선택되어 있다.
- `/order`로 이동한다.
- 주문서에 선택 상품의 수량 `1`이 보인다.
- 주문 완료 후 `/orders`로 이동한다.
- 주문 내역 article에 선택 상품 id와 `1개`가 보인다.
