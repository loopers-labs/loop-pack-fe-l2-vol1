# 장바구니 수량 직접 입력

## 목표와 합의

사용자가 승인한 후보 ①을 구현한다. 기존 +/- 조작에 직접 입력을 더하고,
수량을 지운 뒤 12를 입력하여 Enter 없이 바로 구매해도 주문 수량과 금액이 일치해야 한다.
커밋·푸시하고 main 대상 PR에서 조건부 CI의 실제 선택과 실행 결과를 확인한다.

## 비범위

- API·재고 정책·CI 조건 변경, 새로운 의존성 추가
- 의도적으로 결함을 넣는 실험, PR 병합

## 조사 결과

- CartItemRow는 수량을 output으로 표시하고 기존 setQuantity로 +/-를 처리한다.
- setQuantity는 1 이상의 안전한 정수만 저장하며 localStorage에 영속화한다.
- 구매 클릭은 선택 상품의 현재 수량을 checkout draft에 복사한다.
- 핵심 주문 E2E는 수량 1만 주문하고 있다.

## 결정 사항

- 네이티브 number input(min=1, step=1, max=Number.MAX_SAFE_INTEGER)을 사용한다.
- 유효한 입력은 기존 setQuantity로 즉시 반영한다. 별도의 blur 커밋은 두지 않는다.
- 편집 중 문자열만 로컬 상태로 유지한다. 빈칸·0·음수·소수·범위 초과는 저장하지 않는다.
- blur 또는 Enter에서 편집 문자열을 해제하여 마지막 유효 수량으로 복원한다.
- 기존 +/-와 상품별 접근성 이름을 유지한다.
- 기존 핵심 주문 테스트에 직접 입력 시나리오를 포함한다. 핵심 테스트 개수는 그대로다.
