generator 가 그중 8개를 `e2e-generated/` 에 생성했다. 생성물은 검수 기록(`docs/rfc/week09-e2e-scope.md` 부록 C)과 함께
남겨 두되 `pnpm check` 의 E2E(`e2e/`)에는 포함하지 않는다 — 3단계에서 정한 범위 밖의 시나리오를 늘리지 않기 위해서다.
