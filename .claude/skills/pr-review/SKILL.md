# PR Review — 팀 컨벤션 기준 diff 리뷰

> **용도: 이 레포의 규칙으로 PR을 거른다.** 일반론("가독성 좋게")은 쓰지 않는다.
> 결정적으로 판별되는 규칙은 이미 ESLint·tsc·CI가 잡는다 — 여기서는 **기계가 못 잡는 것만** 본다.
> AI 리뷰는 비결정적이라 참고용이다. required 게이트가 아니고, 최종 판단은 사람이 한다.

## 리뷰 실행 순서

1. **diff 읽기** — 인자의 범위(`base..head`)를 `git diff`로 읽는다. 인자가 없으면 현재 브랜치와 `kjeunn`의 diff. 바뀐 줄이 속한 함수·컴포넌트 전체를 `Read`로 함께 본다. 바뀐 줄만 보고 판단하지 않는다.
2. **억제 규칙 적용** — 아래 *보고하지 않는 것*에 해당하면 목록에서 뺀다.
3. **규칙 대조** — *리뷰 기준*의 규칙 ID마다 diff를 훑는다. 규칙에 없는 지적은 하지 않는다.
4. **리포트 출력** — _리포트 형식_ 그대로. 파일은 수정하지 않는다.

## 보고하지 않는 것 (억제 규칙)

- **ESLint·tsc·prettier가 잡는 것**: import 정렬, `any`, `ts-ignore`, 미사용 변수, `==`, `console.log`, hooks deps, FSD 레이어 역참조(boundaries), 포맷. CI가 결정적으로 막으므로 AI가 다시 말하면 소음이다.
- **스타터·픽스처 코드**: `src/app/api/_data/**`, `src/app/api/auth/**`, `src/app/api/orders/**`, `src/analytics/logger*`·`provider*`·`consoleProvider*`, `src/examples/**`, `docs/**`. 우리가 짠 코드가 아니다.
- **diff 밖의 기존 코드**: 이번 PR이 건드리지 않은 줄의 문제는 별도 이슈이지 이 PR의 지적이 아니다.
- **취향**: 이름이 "더 좋을 수 있다" 수준, 주석 문체, 줄 길이. 규칙 위반이 아니면 쓰지 않는다.

## 확인 없이 쓰지 않는 것

- **"안 쓴다"·"두 벌이다" 주장**은 `Grep`으로 소비처를 찾은 뒤에만 쓴다. 테스트에서 안 부른다고 미사용이 아니다 — 핸들러·픽스처·설정이 소비자일 수 있다. 찾은 소비처를 지적에 함께 적는다.
- **"주석이 틀렸다" 주장**은 주석이 가리키는 코드를 현재 HEAD에서 읽고 대조한 뒤에만 쓴다.

## 규칙 밖이지만 반드시 보고하는 것 — 결함 후보

규칙 ID로 못 부르는 것 중 **실패 경로에서 게이트가 조용히 통과하는 결함**은 억제하지 않는다. 컨벤션 리뷰라도 이건 놓치면 안 된다.

- 조건: 어떤 입력·상태에서(예: 선행 job 실패, 매니페스트 형식 변경, 리포트 파싱 실패) 검증이 실행되지 않거나 항상 통과로 흐르는 경로.
- 형식: _결함 후보_ 섹션에 `파일:줄 — 재현 조건 → 결과 — 제안`. 재현 조건이 없으면 쓰지 않는다.
- 이 섹션은 규칙 위반이 아니므로 규칙 ID 대신 `결함`으로 표시한다.

## 리포트 형식

```
## PR 리뷰 — <base..head>

### 지적 (규칙 위반)
| # | 파일:줄 | 규칙 | 확신 | 무엇이 어긋났나 | 제안 |
|---|---|---|---|---|---|
| 1 | src/x/Y.tsx:12 | Q7 | 높음 | `./Z` 상대 import | `@/x/Z` |

### 결함 후보 (규칙 밖, 실패 경로)
- 파일:줄 — 재현 조건 → 결과 — 제안

### 판단 보류 (맥락 필요)
- 파일:줄 — 규칙 — 왜 확정 못 하나(어떤 맥락이 있으면 위반/비위반으로 갈리나)

### 억제한 것
- ESLint·tsc가 잡는 것 N건, 스타터 코드 N건 — 목록 생략
```

- **확신**: `높음`(규칙 문면에 그대로 걸림) / `중간`(규칙의 취지엔 걸리나 예외일 수 있음) / `낮음`(의심). `낮음`은 지적이 아니라 *판단 보류*에 둔다.
- 지적은 **파일:줄과 규칙 ID가 있어야** 한다. 둘 중 하나가 없으면 쓰지 않는다.
- 같은 규칙의 반복 위반은 한 행에 묶고 줄 번호를 나열한다.
