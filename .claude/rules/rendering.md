# 화면 상태 · 오류 처리 규칙

## 오류는 종류마다 처리 위치가 다르다

| 오류 | 처리 위치 | 화면이 할 일 |
| --- | --- | --- |
| 전송 실패 · 응답 해석 실패 | `shared/api-client.ts`가 사용자 문구를 담은 일반 `Error`로 던진다 | 상태 코드가 없는 실패로 다룬다 |
| HTTP 실패(4xx · 5xx) | `shared/api-client.ts`가 `ApiError(status)`로 변환 | `status`로 분기한다 |
| 세션 만료 | `app/query-client.ts` 공통 처리 — `meta.requiresAuth` 요청의 401, 그리고 `['me']`가 `null`로 성공한 경우 | 만료 처리는 그 공통 콜백에 맡긴다 |
| 로그인 요청의 401 | 로그인 폼 | 자격 증명 오류로 보여준다. `requiresAuth`를 붙이지 않아 만료 처리에서 빠진다 |
| 조회 · 변경 실패 | 그 요청을 건 컴포넌트 | 인라인으로 알리고 복구 수단을 준다 |
| 예상하지 못한 렌더 오류 | `app/(commerce)/error.tsx` | 여기까지 왔으면 화면 단위 실패다 |

- 같은 상태 코드라도 요청의 성격이 다르면 다른 오류다. 401을 한 덩어리로 다루면 로그인 실패가 만료 화면으로 샌다.
- API 계층은 오류를 변환만 한다. router 이동 · store 조작은 호출부에 둔다.
- 던질지 값으로 돌려줄지는 "화면이 분기해야 할 실패인가"로 정한다. 비로그인 `/me`처럼 정상 상태면 `null` 성공으로 둔다.
- 재시도는 오류 종류로 정한다. 다시 보내도 결과가 같은 오류(401 등)는 한 번으로 끝낸다.
- 복구 버튼은 실제로 다시 시도하는 경로에 연결하고, 요청이 도는 동안 비활성화한다 — 조회는 `refetch`, 경계는 Query `reset`, 서버 컴포넌트까지 다시 그려야 하면 `unstable_retry`(reset + refresh).

## 화면 상태 여섯 개를 다 정한다

`초기 대기 · 재조회 · 성공 · 빈 결과 · 오류 · 취소와 오래된 응답`. 정하지 않은 상태가 하나라도 있으면 그 조건에서 무엇이 보일지 아무도 모른다. 이 화면에서 생기지 않는 조건이면 왜 생기지 않는지를 대신 적는다.

- 초기 대기와 재조회를 구분한다. 재조회는 이전 데이터를 유지하고 갱신 중임을 표시한다.
- 빈 결과는 오류가 아니다. 다만 0건이라고 확인한 뒤에 보여준다 — 대기 중에 "없습니다"가 먼저 뜨면 사용자는 조회가 끝난 줄 안다.
- 갱신 실패에도 직전 목록을 지킨다. `placeholderData`는 pending 동안의 값이라 최종 실패를 덮지 못하므로, 마지막으로 성공한 key를 기억하고 데이터는 캐시에서 읽는다.
- 이전 데이터를 보여주는 동안 무엇을 할 수 있는지 정한다. 화면과 URL 보정은 확정된 값(총 페이지 수 등)이 왔을 때 한다.
- 화면에는 현재 조건의 응답만 남긴다. 늦게 끝난 이전 요청의 결과는 자기 queryKey 캐시에만 들어간다.

## 로딩 자리와 접근성

- 로딩 경계는 콘텐츠 단위로 나눈다. 한 조각 때문에 화면 전체를 비우지 않는다.
- 대기 화면은 실제 콘텐츠의 클래스 · 타이포그래피를 그대로 써서 크기 계약을 실제 콘텐츠가 만들게 한다.
- 대기 문구에는 사람이 읽을 말을 쓴다. `p11` 같은 내부 id는 화면에 내보내지 않는다.
- 교체 때 이동이 남으면 교체 순간에만 이전 높이를 고정했다 놓는다. 상시 여백 예약과 다르다.
- 화면마다 `h1` 하나를 데이터 대기 없이 셸에서 낸다.
- 진행 상태는 `role="status"`로 전한다. 이미 있는 줄에 갱신 표시를 얹을 때는 그 줄에 `aria-live="polite"`를 두어 자리를 밀지 않는다. 오류는 `role="alert"`, 장식용 골격은 `aria-hidden`이다.
- 이동은 `Link`, 동작은 `button`이다. 의미 있는 이미지에는 `alt`, 같은 종류가 여럿인 랜드마크에는 `aria-label`을 준다.
- 열고 닫는 컴포넌트를 만들면 키보드 · 포커스 · `aria-*`를 누가 책임지는지 API에 드러낸다.
